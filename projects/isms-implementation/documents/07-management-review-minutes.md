# Management Review — Minutes Template

**Organisation:** Northwind Cloud Services
**Clause reference:** ISO/IEC 27001:2022, Clause 9.3
**Meeting cadence:** Quarterly, chaired by CEO, minuted by Head of Security & Compliance

Clause 9.3 specifies mandatory inputs and outputs. This template exists so
neither gets missed — a review that skips an input, or produces no
recorded output, is itself a common audit finding.
